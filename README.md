# Bitcoin-TestNet4-Analysis
Analysis of Bitcoin TestNet4 transaction
## 1. Question étudiée

Comment fonctionne une transaction Bitcoin sur le réseau TestNet4 ?

## 2. Objectif du projet

Comprendre les principales étapes d'une transaction Bitcoin, notamment les entrées (Inputs), les sorties (Outputs), les frais de transaction, les confirmations et les UTXO.

## 3. Méthodologie

Ce projet utilise une approche documentaire et analytique pour expliquer le fonctionnement des transactions Bitcoin à partir d'une expérience sur TestNet4.

## 4. Résultats obtenus

L'analyse de deux transactions sur Bitcoin TestNet4 a permis d'observer le fonctionnement des Inputs, des Outputs et des frais de transaction.

Elle a également montré comment une sortie d'une première transaction peut être utilisée comme entrée dans une deuxième transaction, illustrant ainsi le modèle UTXO.
